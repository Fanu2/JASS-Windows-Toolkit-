# JASS Quote & Poster Studio v1.0

A lightweight, local-first **PySide6 quote and poster creator** for turning quotes, poetry, sayings and short passages into attractive poster images.

## Features
- Live poster preview
- Quote, author and subtitle editing
- Motivational, romantic, wisdom, poetry and minimal templates
- Gradient, solid, radial and warm backgrounds
- Custom colors for background, text, accent and border
- Optional diagonal pattern and dark overlay
- Font family, size, bold/italic and alignment controls
- Adjustable content padding
- Drag preview vertically to fine-tune composition
- Random poster generator
- PNG and JPEG export
- 1200×1600, 1080×1350, 1080×1080, 1600×900 and 2048×2048 presets
- Custom export dimensions up to 6000×6000
- Save/load poster projects as JSON
- Local/offline; no database, cloud or AI dependency
- No automatic deletion or modification of source files

## Install on MX Linux / Debian
```bash
sudo apt update
sudo apt install python3 python3-pip
python3 -m pip install PySide6
python3 JASS_Quote_and_Poster_Studio_v1.0.py
```
