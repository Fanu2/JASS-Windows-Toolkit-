# JASS TextLab Studio

**JASS TextLab Studio** is a configurable, multilingual **text-generation and testing workbench** built with PySide6.

It started from the idea of a themed Lorem Ipsum generator, but the application is designed as a practical developer and content-testing utility rather than a novelty generator.

## What it is useful for

TextLab can quickly create controlled text for testing:

- PySide6 / Qt interfaces
- text editors and document viewers
- search and filtering
- database text fields
- tables, cards and dashboards
- pagination
- word wrapping and long paragraphs
- copy/paste
- Unicode and font rendering
- multilingual applications
- RTL/Shahmukhi interfaces
- PDF/HTML/text export
- large-text performance
- reproducible test cases

## Main features

### ✦ Generator

Generate text using:

- built-in language corpora
- your own corpus
- theme vocabulary
- configurable paragraph count
- configurable words per paragraph
- deterministic random seed
- optional punctuation patterns
- optional numeric/ID data
- optional Unicode stress characters
- background generation thread so the GUI remains responsive

### 📚 Corpus

Load, edit and save local corpora.

**EPUB book import** is supported. TextLab reads the EPUB package locally, follows the book spine, extracts readable XHTML/XHTML content, and reports basic metadata such as title, author, section count, word count and character count.

Built-in examples include:

- English
- Punjabi — Gurmukhi
- Punjabi — Shahmukhi
- Mizo
- Hindi
- Bengali
- Assamese
- Tamil
- Telugu
- mixed multilingual text
- programming/technical text
- Avengers-themed source text

External TXT, Markdown, CSV and EPUB files can also be loaded. EPUB files are imported locally and converted into plain text for corpus use.

### 🧪 Text Tests

Paste generated or real application text and run diagnostics.

The diagnostics report:

- character count
- word count
- unique words
- lines
- paragraphs
- whitespace
- vocabulary ratio
- RTL-range characters
- combining marks
- control characters

Unicode Inventory lists the Unicode code points occurring in the supplied text.

There is also Unicode NFC normalization for text-cleanup/testing workflows.

### 📊 Statistics

The generated output can be inspected for:

- characters
- words
- lines
- paragraphs
- unique words
- UTF-8 byte size
- selected language preset
- generation mode
- seed

## Export

Generated text can be saved as:

- TXT
- Markdown
- HTML
- JSON
- CSV

JSON exports retain useful generation metadata, including the selected preset and seed.

## Reproducible test data

Enter an integer in **Seed** to make generation deterministic.

For example:

```text
Seed: 12345
```

Generate the same configuration again with the same seed and the output will be reproducible.

This is particularly useful when reporting UI bugs because the exact same test text can be regenerated.

Leave Seed blank when random output is preferred.

## Installation

Python 3.10+ is recommended.

Install PySide6:

```bash
python3 -m pip install PySide6
```

On Windows:

```powershell
py -m pip install PySide6
```

## Run on MX Linux / Debian

From the directory containing the file:

```bash
python3 JASS_TextLab_Studio_v2.0.py
```

If you use a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install PySide6
python JASS_TextLab_Studio_v2.0.py
```

## Run on Windows

```powershell
py -m pip install PySide6
py .\JASS_TextLab_Studio_v2.0.py
```

## Typical developer workflow

### Test a multilingual UI

1. Select **Mixed Multilingual**.
2. Generate several paragraphs.
3. Copy the output into the application being tested.
4. Check font rendering, wrapping, clipping and search.
5. Paste the same text into **Text Tests**.
6. Run diagnostics and Unicode Inventory.

### Test a database field

1. Generate 500–10,000 words.
2. Enable numbers/IDs.
3. Export CSV or JSON.
4. Import the generated data into your test database.

### Reproduce a bug

1. Select a corpus.
2. Set paragraph/word counts.
3. Enter a fixed seed.
4. Generate.
5. Save the output.
6. Reproduce the bug using exactly the same data.

### Test RTL / Shahmukhi

1. Select **Punjabi — Shahmukhi**.
2. Generate text.
3. Paste into the target application.
4. Check right-to-left alignment, cursor movement, selection, search and wrapping.

## Privacy

TextLab is designed for local/offline operation.

It does not require an online AI service, account, API key or cloud backend.

External corpus files are read from your local filesystem.

## Safety

TextLab is a generator/test utility.

It does **not**:

- delete files
- rename files
- move files
- modify source corpus files unless you explicitly save over a chosen path
- upload generated text
- call an external AI service

## Architecture

The application deliberately keeps the generation engine simple:

```text
PySide6 UI
   │
   ├── Generator
   │     ├── Built-in corpus
   │     ├── External corpus
   │     ├── Theme vocabulary
   │     ├── Seeded RNG
   │     └── Test-data options
   │
   ├── Corpus Workspace
   │
   ├── Text Diagnostics
   │
   └── Statistics / Export
```

The generator runs in a `QThread`, allowing larger generation jobs without blocking the main interface.

## Version

**v2.0.0**

This is the first practical TextLab Studio release.

The original themed-Ipsum concept is retained as an optional stress-testing mode, but the application is now positioned as a general-purpose multilingual text generation and testing workbench.

### v2.0 EPUB and Meaningful Generation

TextLab v2.0 adds a lightweight, dependency-free EPUB importer and meaningful generation modes.

**Meaningful generation modes:**
- Random sentences — selects complete sentences, preserving their grammar and meaning.
- Random paragraphs — selects complete paragraphs from the corpus.
- Sequential excerpts — walks through corpus paragraphs in order, producing coherent excerpts.
- Random words — retained specifically for stress-testing interfaces.
- Theme vocabulary — retained for synthetic/stress-test data.

**EPUB features:**
- Import `.epub` directly.
- Read the EPUB package locally.
- Follow the book reading spine.
- Extract XHTML/HTML without requiring BeautifulSoup or another external parser.
- Read basic metadata such as title, author, language, publisher and date when supplied.
- Count chapters/sections, words and characters.
- Show an EPUB information panel.
- List imported sections/chapters.
- Select an individual chapter/section for generation.
- Use the entire book as the corpus.
- Preserve Unicode and normalize extracted text to NFC.
- Handle URL-encoded EPUB paths and common EPUB directory layouts.

This makes romance, literature and multilingual EPUB collections practical source material for TextLab.
